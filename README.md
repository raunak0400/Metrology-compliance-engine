# Project README

This project contains the legal metrology label verification pipeline.

## Requirements

- Python 3.10+
- pip
- Git

Install the required Python packages:

```bash
pip install opencv-python numpy pillow
```

If your project uses additional dependencies, install them as needed.

## Run the project

From the project folder:

```bash
python legal_metrology_label_verification_v3.py
```

## Git setup

Initialize Git in the project folder:

```bash
git init
```

Add files:

```bash
git add .
```

Create your first commit:

```bash
git commit -m "Initial commit"
```

## Connect to GitHub

Create a new repository on GitHub, then run:

```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Replace the URL with your actual GitHub repository link.

## Update later

After making changes:

```bash
git add .
git commit -m "Updated project"
git push
```

## Notes

- Do not push sensitive information, API keys, or credentials.
- Add a .gitignore file if you want to exclude temporary files, virtual environments, or generated outputs.
